# electrochemistry-101--diffusion-control
Interactive HTML tool for teaching diffusion control in electrochemistry: concentration profiles, Cottrell, Randles–Ševčík, Sand and Warburg analysis, all driven by one simulated system.
A single-file, offline-capable teaching tool for graduate electrochemistry. One parameter panel defines the simulated system (n, area, concentration, D, temperature), and every panel on the page responds: the growing diffusion layer, the Cottrell decay, simulated voltammograms, chronopotentiometric transitions and the Warburg impedance. Four techniques then recover the diffusion coefficient that was set, so students see where the number comes from and what breaks it. Includes a finite-difference sandbox, a pasted-data mode for students' own chronoamperometry curves, and a worksheet. Temperature acts on D through the Stokes–Einstein relation, with the coupling toggleable.
